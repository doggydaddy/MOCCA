# Archived permutation modules

The frozen legacy edgewise, uncorrected-p permutation pipeline is stored in
`uncorrected_p_pipeline_2026_08_26/`.  It was moved out of the active build on
2026-08-26 while the bundle-level permutation FWER path was being developed.

The archive contains its own build file and provenance manifest.  Data,
generated permutation tables, compiled binaries, and corrected FWER routines
are intentionally not part of the archive.
